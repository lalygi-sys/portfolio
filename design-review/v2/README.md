# Главная портфолио — редизайн по подробному брифу

Локальная версия: http://127.0.0.1:8081/. Проверено 26–27 сентября 2026 года.

Один разговорный hero приводит к трём одинаково устроенным карточкам. Убраны повторная плашка с именем, боковой манифест, полоса стажа и типографические обложки. Карточки показывают задачу, вклад, результат и реальную стадию проекта. Исследования оставлены двумя компактными ссылками. About сокращён; история объясняет развитие ответственности внутри Garage Eight. Использован Figtree, нейтральная палитра и отдельные цвета тёмной темы.

В текущем опубликованном контенте нет настоящих изображений кейсов или портрета. Главная поэтому завершена как текстовая композиция. Компонент карточки поддерживает реальные обложки и изображения разделов из редактора, с переходом к текстовой версии при ошибке загрузки.

## Что можно дополнить реальными материалами

- Текущий профессиональный статус и город: до подтверждения показано Previously at Garage Eight.
- Портрет или короткое видео с вами для About.
- Разрешённые скриншоты интерфейсов, схемы или артефакты для превью кейсов.
- Актуальный PDF CV, если вместо Request CV нужно скачивание.

Контент из редактора сохраняет приоритет: редактура исходных текстов главной применяется только при точном совпадении с исходным значением; изменённые заголовки, описания, результаты, стадии и About выводятся из CMS. Изменений удалённой базы и публикации сайта не выполнялось.
