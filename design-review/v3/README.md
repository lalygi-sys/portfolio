Локальная версия: http://127.0.0.1:8081/

## Что изменено

- Главная `/`: новый hero, последовательное появление текста, однократный декоративный курсор, три выбранных кейса с реальными обложками и метриками, контакты с иконками. About и отдельный исследовательский блок перенесены с главной.
- `/work`: семь проектов в двух непустых категориях. Карточки раскрываются inline; у пяти продуктовых работ есть переход к полному кейсу.
- `/about`: краткое введение из CV и четыре этапа реальной карьеры.
- Существующие пять `/work/:slug` сохранены, получили реальные обложки и возврат к Work. Финансовый плейсхолдер исходного Rebate outcome больше не выводится.
- `/admin` сохранён; публичные ссылки Editor удалены. Проверен экран входа, без изменения аккаунта или данных.
- В навигации обычная ссылка CV открывает предоставленный PDF в новой вкладке. Сохранены темы, активные пункты Work/About и переход к `/#contact` с внутренних страниц.

## Проекты и данные

`src/lib/projects.ts` дополняет опубликованные записи существующего CMS локальными презентационными полями: категория, продукт, обложка, alt, метрики и краткое описание. Сохраняются CMS title/summary/contribution/outcome, role, period, featured, sort_order, links и загруженная обложка. При изменении outcome в редакторе исходные метрики скрываются, чтобы не противоречить новому тексту. Снятые с публикации записи не восстанавливаются из локальных данных.

На главной: KYC/KYB, Rebate, Standalone IB Partner Portal.
На Work дополнительно: New IB business model, Participant recruitment, Window configurator, Pizza ordering experience.

Draft-структура: Language-learning product, Information/application security product, Copy Trading. Публично они не отображаются; чужие роли, результаты и метрики не перенесены. Для их публикации нужны личный вклад, контекст, решения, результаты и визуалы Татьяны. Пустая категория Independent projects пока скрыта.
